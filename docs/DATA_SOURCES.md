# Data Sources

## MODIS Vegetation Indices

Dataset: MODIS Vegetation Indices 16-Day Global 250 m  
Earth Engine ID: `MODIS/061/MOD13Q1`

Variables used:

- NDVI
- EVI
- SummaryQA

Analysis period: 2001–2025.

---

## CHIRPS Precipitation

Dataset: Climate Hazards Group InfraRed Precipitation with Station Data  
Earth Engine ID: `UCSB-CHG/CHIRPS/DAILY`

Variable used:

- precipitation

Periods:

- project analysis: 2001–2025;
- drought climatology: 1981–2025.

---

## ERA5-Land Temperature

Dataset: ERA5-Land Monthly Aggregated  
Earth Engine ID: `ECMWF/ERA5_LAND/MONTHLY_AGGR`

Variables verified:

- temperature_2m
- temperature_2m_min
- temperature_2m_max

Analysis period: 2001–2025.

---

## Administrative Boundaries

Source: geoBoundaries.

Administrative level: Nigeria ADM1.

The final study area contains 19 Northern Nigerian states.
